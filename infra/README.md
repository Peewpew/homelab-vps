# Infra

This folder contains VPS setup instructions and helper scripts.

## Contents

- `ufw.sh`: Firewall setup
- `docker-install.sh`: Install Docker & Docker Compose
- `first-login.md`: Notes for initial VPS login and setup
- `fail2ban.md`: Optional security configuration

## Notes

- Contains information about **system-level setup**
- Helps rebuild the VPS from scratch if needed
- Not tied to any single application
